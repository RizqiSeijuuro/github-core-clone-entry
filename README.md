A standalone, GitHub-compatible git forge in one Node 22 process: git smart HTTP (upload-pack v2,
receive-pack v0), the REST v3 API, GraphQL v4, and a Model Context Protocol endpoint — all served
from an in-memory store, with no database, no UI, no package install and no `git` binary.

## Run it

```sh
node --experimental-strip-types main.ts
```
